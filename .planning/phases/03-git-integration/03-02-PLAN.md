  <name>Task 3: Implement status.rs with GitStatus struct for uncommitted changes</name>
  <files>src/git/status.rs</files>
  <action>
Create src/git/status.rs with:

1. `GitStatus` struct with fields:
   - staged_count: usize
   - unstaged_count: usize
   - unpushed_count: usize

2. `GitStatus::check(path: &Path) -> Result<Self>` method:
   - Open repository at path (return error if not git repo)
   - Get statuses with repo.statuses(None)
   - Count staged: INDEX_NEW | INDEX_MODIFIED | INDEX_DELETED | INDEX_RENAMED
   - Count unstaged: WT_MODIFIED | WT_DELETED | WT_RENAMED (not WT_NEW - untracked files don't count)
   - Call count_unpushed_commits helper
   - Return GitStatus

3. `count_unpushed_commits(repo: &Repository) -> Result<usize>` helper:
   - Get HEAD (return 0 if no HEAD - empty repo)
   - Get local branch from HEAD shorthand
   - Get upstream (return 0 if no upstream - local-only branch)
   - Create revwalk, push HEAD, hide upstream
   - Count commits in walk
   - Handle errors gracefully (return 0, not error)

4. `GitStatus::has_warnings(&self) -> bool` method:
   - Return true if any count > 0

5. `GitStatus::warning_message(&self) -> String` method:
   - Per CONTEXT.md format: "3 uncommitted changes, 2 unpushed commits"
   - Combine staged + unstaged as "uncommitted changes"
   - Handle all combinations (changes only, unpushed only, both, neither)

Reference RESEARCH.md for Status flag patterns and revwalk pattern.
